# 现代伤害系统 / Modern Damage System

Minecraft Fabric 战斗附魔模组，为 MC 引入完整的现代化伤害乘区系统。
A comprehensive combat & enchantment mod for Minecraft Fabric, featuring a modern damage multiplier system.

- **版本 / Version:** v2.0.3
- **MC版本 / MC Version:** 26.2 Fabric

---

## 功能 / Features

### 战斗附魔系统
- 23+ 种自定义附魔，分为暴击、攻击、防御、Debuff、属性五大系列
- 支持正/负（诅咒）等级附魔
- 完整的暴击率/暴击伤害/独立乘区伤害公式

### 内容
- **自定义合成台**：4本同级附魔书 → 1本升级书
- **配方书**：右键查看所有附魔/药水/材料合成配方
- **新药水**：冰霜、剧毒、破甲、易伤（普通/喷溅/滞留/药水箭）
- **敌对生物适配**：怪物自动获得附魔，攻击时挂Debuff
- **HUD显示**：实时显示武器/护甲属性
- **战利品注入**：自动注入所有结构箱子
